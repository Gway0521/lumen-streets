Lumen Streets繁體中文

Save a scene. Share a night.

In Capture → Scene files, save a .lumen-view.json file and use Open scene to return to it. It keeps camera, lighting, composition and traffic. Online map tiles are still required; map snapshots and imported GLBs are not included. If roads change, unmatched traffic restarts.

Links and embeds

Copy a view link or embed code from Capture. Links keep camera settings and start fresh traffic; embeds can also include captions and shading. A localhost link works only on its own computer. Shared files and URLs disclose their location and settings.

Earlier scenes

Old 2D .lumen.json files and player links remain readable in the legacy player. They cannot be imported into the 3D editor. Keep the original file; changing its extension does not convert it.

Map credit

Keep visible OpenStreetMap attribution with shared views and embeds.

保存場景，分享這一晚

在匯出 → 場景檔保存 .lumen-view.json，再用開啟場景還原視角、光線、構圖與車流。仍需線上圖磚；檔案不包含地圖快照或本機 GLB。道路資料改變時，無法配對的車流會重新開始。

連結與嵌入

從匯出面板複製視角連結或嵌入程式碼。連結保留視角設定並重新開始車流；嵌入可加上標題與柔暗。localhost 連結只能在原電腦使用。分享檔案或網址也會公開其中的地點與設定。

舊版場景

2D .lumen.json 檔案與舊連結仍可在舊播放器讀取，但不能匯入 3D 編輯器。請保留原檔，改副檔名不會轉換格式。

地圖署名

分享與嵌入時，請保留可見的 OpenStreetMap 署名。
