Lumen Streets繁體中文

Save a scene. Share a night.

Return to the same moment

Choose Save & share scene → Download scene. Send the .lumen.json file to another device, then use Open scene file in the editor or player. It keeps the map, view, settings and exact traffic moment. Files open in your browser without being uploaded.

Keep the app available on the other device too. A scene file opens inside Lumen Streets, rather than on its own.

Share a link

For an included city, copy the Player link. It opens the view and settings with fresh traffic. Download a scene file when you want to preserve the exact moment.

If the app is running only on your computer, its link will work only there. Send a scene file instead, or share a link from a publicly reachable website.

Put it on a website

Copy the Embed code into your page. For a custom place, save the scene file beside the hosted app, for example scenes/kyoto.lumen.json, and use this player address:

player.html?scene=scenes/kyoto.lumen.json

Use the player's full website address when embedding from another website. The scene file must be served from the same website as the player. Anyone with access to a public scene file can see its location and settings.

Quiet when out of view

The player pauses when it leaves the screen or moves to a background tab. If you prefer reduced motion, it starts paused. Press Play whenever you want the traffic to move.

Map credit

Scene files contain OpenStreetMap data under ODbL. Keep source data and attribution with shared files, and keep the player's credit visible.

保存場景，分享這一晚

回到同一個時刻

選擇保存與分享場景 → 下載場景檔。將 .lumen.json 傳到另一台裝置，再於編輯器或播放器選擇開啟場景檔。地圖、取景、設定與當下車流都會保留，檔案在瀏覽器處理，不會上傳。

另一台裝置也需要能開啟 Lumen Streets；場景檔需由網站讀取，無法單獨執行。

分享連結

預載城市可以直接複製播放器連結。連結保留取景與設定，重新開始播放車流；若要保留當下的車流，請下載場景檔。

若網站只在自己的電腦執行，連結也只能在那台電腦開啟。此時可分享場景檔，或使用其他人也能連上的網站網址。

放進自己的網站

將嵌入程式碼貼到網頁即可。自訂地點需先下載場景檔，放到播放器所在網站，例如 scenes/kyoto.lumen.json，再使用：

player.html?scene=scenes/kyoto.lumen.json

從其他網站嵌入時，請使用播放器的完整網址。場景檔必須與播放器放在同一個網站；公開場景檔也會公開其中的地點與設定。

離開畫面時休息

播放器離開可見範圍，或分頁移至背景時，會暫停播放。若裝置設定為減少動態效果，場景會先保持靜止，按播放即可讓車流開始移動。

地圖署名

場景檔包含受 ODbL 規範的 OpenStreetMap 資料。分享檔案時請保留來源與署名，也請保留播放器上可見的地圖署名。
