The archive includes the editor, server, build scripts, dependency lockfile and setup documentation. Extract it, install Node.js 24 and Python 3.12 (with pip and venv), then run npm ci and npm run build. Run npm start to serve the website.

When distributing a modified version or offering it as a network service, follow the AGPL source-sharing requirements and provide the corresponding source for the version you run.
