# 建築資料與高度

[English](BUILDING-HEIGHTS.md)

所有位置使用同一建築服務。Node 按需求讀取 Overture 全球 PMTiles；Python 在背景發現並匹配有地理覆蓋的高度來源。輪廓及實測資料完整度依地區不同。

## 來源與選用

| 來源 | 用途 |
| --- | --- |
| Overture Buildings | 固定版本的輪廓、部件、原始高度／樓層及各欄位來源 |
| GHS-BUILT-H R2023A | 2018 年、100 公尺解析度的 ANBH 區域高度背景 |
| 日本 PLATEAU | 依地理範圍發現 CityGML 建築／部件、量測高度及樓層 |
| EUBUCCO v0.2 | 自動查找地理分區、匹配輪廓及高度來源 |

[來源目錄](../data/building-sources.json)記錄版本及存取方式。GHS 網格平均高度屬於區域估算；機器學習及來源不明的高度也保留估算標記。PLATEAU 支援 CityGML 2 LoD0／LoD1。圖磚和匯出附带實際來源，見[來源與授權](../ATTRIBUTION.md)。

選用順序為相容的地圖／量測高度、樓層換算、細緻估算、區域背景、依用途及輪廓產生的固定估算。樓層以每層 3.2 公尺加上可用屋頂高度換算。原始缺值與顯示高度分開保存。

高度須為有限且垂直關係合理的數值，上限 1200 公尺。補充輪廓須達到交集／聯集至少 0.65、交集／較小面積至少 0.8；近似同分或重複占用的匹配會被拒絕。整棟高度不能直接套給部件。已審核地標保有自己的幾何與高度。

## 傳送與背景更新

瀏覽器向 /api/buildings/manifest.json 取得全球圖磚模板，再下載 zoom-14 圖磚。服務按 GERS ID 重組跨圖磚輪廓，保留庭院、部件與底部高度。單次重組最多 25 個來源圖磚，單一回應解碼後上限 8 MiB。

圖磚採字典編碼、gzip 與 ETag。桌面／手機同時下載 4／2 個，編碼快取為 24／8 MiB。初次瀏覽可能先看到估算；待補充的視角在閒置 30 秒後更新，部分完成的結果約一小時後重新檢查。匯出期間固定資料版本。

GHS 與國家資料各有一條背景佇列，每條同時一個工作、最多等待 96 個。不同訪客共用工作及快取。部署容量、Python 環境及快取目錄見[部署指南](HOSTING.zh-TW.md)。

## 離線分析

scripts/buildings/build.py 可輸出指定範圍的圖磚、來源收據、稽核檔及第 1 版資料清單，供重現分析或製作自訂資料集。這與網站第 2 版全球服務合約分開。離線工具另支援附有 CRS、來源、授權及高度定義的本機 3DBAG／通用向量與 GeoTIFF。指令與限制見[英文文件](BUILDING-HEIGHTS.md)。
