# Lumen Streets 架構

[English](3D-ARCHITECTURE.md) · [立面與照明](3D-FACADES.zh-TW.md) · [地標投稿](3D-LANDMARKS.zh-TW.md)

Lumen Streets 使用 MapLibre 與 Three.js 共用 WebGL 2 畫面及深度緩衝。地圖負責全球地景、鏡頭和圖磚快取；批次幾何負責立面、地標與移動燈光。編輯器、匯出與嵌入視角使用同一套渲染器。

## 執行與操作

使用 Node.js 24，執行 `npm ci`、`npm run dev`，開啟 `http://127.0.0.1:5180/`。`/three.html` 也通往相同編輯器。正式建置使用 `npm run build`，再執行 `npm start`，連接埠為 5180。

拖曳平移、按住右鍵旋轉與調整俯角、滾輪縮放；手機使用雙指。探索面板提供八個城市及地點搜尋。設定可調整亮度、車流、視角、環繞、畫質及即時地標名稱。隱藏控制後只留下夜景。

## 資料與幾何

城市快照保留 OSM 高度、樓層、建築組合和庭院。獨立展示目錄依地理位置載入 51 組地標，含既有 6 組模型；廣州、高雄、橫濱、紐約使用全球向量圖磚，未新增道路或鐵道快照。詳見[展示區與容量評估](SHOWCASE.zh-TW.md)。快照以外的建築使用 zoom 14 向量圖磚。每個 MultiPolygon 會拆成個別輪廓，再判定圖磚歸屬；`hide_3d` 外殼會略過。快照與即時圖磚依實際輪廓去重，避免用矩形涵蓋範圍刪掉整組建築。

去重也會檢查多個快照部件共同涵蓋的外殼，以及圖磚內輪廓與高度範圍相近的重複量體；裙樓、不同底部高度的部件和庭院分別保留。

全球圖源缺少高度及樓層時會使用 5 公尺。圖磚中的 5 公尺無法區分實測矮房與預設值，因此保留來源高度；不會把整區任意拉高。[上游高度計算](https://github.com/openmaptiles/openmaptiles/blob/master/layers/building/building.sql)

`VITE_LUMEN_TILEJSON_URL` 可指定相容的 OpenMapTiles 來源，預設為 OpenFreeMap。平移不會呼叫公共 Overpass 服務；搜尋經由專案的伺服器入口。城市快照也需要線上底圖。地圖服務失敗時，畫面提供重試。

立面使用九種窗戶排列、低彩度建材色、局部外觀照明與紅色警示燈。這些屬於美術推估。水面反射、路燈與車流同樣是視覺模擬。Bloom 使用單次畫面擷取與低解析度模糊；不會為每扇窗建立實體光源。

公園保留草地與疏密不同的樹群。林地使用共用幾何的立體樹冠與樹幹；沒有林地資料的公園只安排少量推估樹群，明確標示的草地保持開闊。道路、水面與建築遮罩排除植被，個別樹木位置屬於美術推估。樹木在街區尺度顯示，合併為一次繪製。夜色壓低建築本體與地面的亮度，保留窗光、街燈和輪廓照明。

植被及照明參考 [Mapbox Standard](https://docs.mapbox.com/map-styles/guides/standard-styles/) 與 [MatrixCity](https://city-super.github.io/matrixcity/) 的城市場景。

上述數字不包含瀏覽器、底圖或解碼中的完整記憶體。超出立面預算的建築改用有方向的實例量體，保留來源高度。簡化量體無法保留所有庭院與凹角。

CityStream 同時只處理一個建模工作及一個合併後的後續要求。每次解碼並處理一個圖磚，只快取壓縮資料。舊幾何、燈光貼圖與地景資源在替換後釋放。地圖遠景會卸載立面、車流和地景快取；隱藏分頁停止車流繪製。

## 匯出與保存

構圖提供桌機、超寬螢幕、方形、平板、手機及自訂比例。可拖曳地圖調整內容，也可切換全螢幕構圖。縮小預覽區時會補償鏡頭縮放，保留相同畫面與建築細節。

- PNG：最長邊 1920、2560 或 3840 像素。
- GIF：6 秒、10 fps、最長邊 720 像素。
- 影片：30 秒至 5 分鐘、30 fps、最長邊 2560 像素。優先 MP4／AVC，支援時以 WebM／VP9 替代。

固定時間戳讓片長不受編碼速度影響。大型影片串流寫入瀏覽器暫存空間，上限 1.5 GB；記憶體備援上限為 250 MB。影片結尾直接重播。

三種格式共用柔和壓暗、邊緣亮度、範圍、地點文字及地標名稱。字體使用專案內附的 Cormorant Garamond 與 Noto Serif TC。完成、失敗或取消後恢復車流、時間、播放、解析度與操作；支援的裝置會在匯出時保持螢幕喚醒。

視角連結保存鏡頭、燈光、車流密度、播放與語言；嵌入視角也可帶入文字和壓暗設定。場景檔保存構圖及車流時刻，以道路端點重新連接車輛。圖資變更時，無法配對的車流重新開始。場景需要連線載入圖資，匯入模型另存於投稿包。

## 驗證

執行 `npm test`、`npm run check:presets`、`npm run check:docs`、`npm run build`。開啟開發伺服器後，`npm run check:3d:browser` 驗證渲染、匯出、全球移動與資源釋放；`npm run check:3d:capture` 驗證直式尺寸、構圖、場景還原、取消與投稿包。瀏覽器視窗模擬和實體手機測試分開記錄。

`node scripts/check-3d-landscape.mjs` 使用實際 Canvas 像素驗證植被排除範圍、草地留白、資料順序，以及跨城市與附近地點的搜尋跳轉。
