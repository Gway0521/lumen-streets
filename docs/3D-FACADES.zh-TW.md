# 建築立面與景觀照明

[English](3D-FACADES.md) · [3D 架構](ARCHITECTURE.zh-TW.md)

夜景分成室內活動、外牆材質與建築景觀照明三層：住宅保持較安靜，商業樓層呈現成組活動，少數冠部與輪廓成為天際線焦點。來源高度與建築輪廓不變。這是程序美術設計，不是實地窗戶調查或即時燈光資料。

## 九種立面

| 分類 | 窗戶大小與排列 | 材質及夜間表現 |
| --- | --- | --- |
| 低層住宅 | 小型獨立窗，保留大面積實牆 | 混凝土、暖灰；暖色室內光 |
| 集合住宅 | 成對窗，每三層微幅錯列 | 中性石材；按房間亮燈 |
| 橫向辦公樓 | 寬而淺的帶窗，中間保留柱與窗間牆 | 銀灰；同層辦公室成組亮燈 |
| 玻璃帷幕 | 大片模組玻璃，連續辦公區 | 藍灰、青灰玻璃；中性及冷白 |
| 飯店 | 細長客房窗、穩定房間間距 | 石灰色、古銅灰；暖窗與局部冠部光 |
| 垂直高塔 | 高窗、分組肋柱、較暗垂直間隔 | 深灰玻璃；選擇性邊緣及上部燈條 |
| 石材／公共建築 | 高窄拱窗、較厚實牆間隔 | 石材與褐灰；暖色掠射光 |
| 工業建築 | 高側寬窗，下部以實牆為主 | 金屬灰；克制照明 |
| 造型塔樓 | 錯列玻璃與局部曲線燈帶 | 玻璃；少量流線輪廓光 |

優先採用已有用途標籤；缺少資料時依高度、面積、輪廓複雜度及固定種子推估。八組低飽和材質讓石材、灰色金屬、古銅灰、深灰與藍綠玻璃在夜間仍有細微差別。精細網格與遠景實例保留同一分類、配色和種子；低樓合併仍屬近似。

景觀照明包含冠部細帶、選擇性的垂直邊緣、上部肋條、曲線與局部洗牆。大部分建築沒有裝飾燈。以香檳金、白色為主，冰藍、青綠與紫色較少。既有地標採明確的美術配色，按構件上下界定位照明；支架、實心尖塔不再套窗戶。曲面構件使用圓柱座標並處理接縫。

部分高樓屋頂角落和地標實際尖端加入紅色航空警示燈。選擇規則是美術推估，不代表當地法規或實際設置。部分常亮、部分以兩秒模擬週期明滅，同棟共用相位；暫停與匯出沿用場景時間。全視野最多 4,096 個有深度遮擋的燈點。

## 成本與限制

每個精細頂點增加四個浮點數，表示分類／地標配色、底部、頂部與牆寬：桌機 700,000 頂點上限約增加 10.7 MiB，手機 280,000 頂點約增加 4.3 MiB。遠景實例沿用原種子欄位編碼分類，不增加步幅。警示燈最多增加 64 KiB 屬性及一次繪製；這些數字不含 CPU 複本、Worker 與驅動程式成本。

分類與種子維持 flat 插值，避免逐像素變動造成雪花雜訊。遠景整合窗光能量，燈條以導數抗鋸齒並限制發光寬度。洗牆是立面的發光近似，不會照亮鄰樓、產生實體陰影或加入水面反射。不增加逐窗網格、貼圖下載或大量實體光源。

開啟開發伺服器後執行 `node scripts/check-3d-architecture.mjs`，可取得九種實際 shader 樣本及札幌、上海、台北、倫敦全球資料畫面，存於不追蹤的 `artifacts/3d-architecture/`。另執行種子雜訊回歸、匯出／釋放與一般瀏覽器測試。必須實際目視檢查，測試通過不等於美術驗收。
