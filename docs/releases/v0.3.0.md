# v0.3.0

Explore a continuous 3D city nightscape, from skyline landmarks to quiet waterfronts.

- Pan, rotate and tilt through global maps with architectural lighting, vegetation, water reflections and simulated traffic.
- Start in eight curated districts across China, Taiwan, Japan and the United States, with 51 modeled landmarks and optional on-screen names.
- Stream building footprints and heights through the global service. Overture, GHS-BUILT-H and geographically matched PLATEAU/EUBUCCO data retain their sources and estimate status.
- Recover from temporary building-service failures with bounded retries and a Retry control for the current view.
- Export framed PNGs, six-second GIFs and 30-second to five-minute videos, with desktop/phone ratios, titles and edge shading.
- Save scenes, share view links, embed nightscapes and prepare local GLB contribution packages.

## Upgrading

Self-hosting requires **Node.js 24 and Python 3.12** with pip and venv, plus a writable building-data cache. The editor needs WebGL2 and online map services. See [Hosting](../HOSTING.md).

Earlier 2D scene files remain readable in the legacy player. New 3D scenes use a separate format. Height coverage varies by location; estimates remain identified.

## Downloads

- **lumen-streets-v0.3.0-site.tar.gz** — built website, Node backend and Python worker sources. Install the host prerequisites, extract, then run npm start.
- **lumen-streets-v0.3.0-source.tar.gz** — source, tests and build instructions.
- Each archive has a companion **.sha256** checksum.
