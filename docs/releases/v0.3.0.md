# v0.3.0 — Unreleased

Current development version: `0.3.0-dev.0`. The 3D architecture is integrated; this is not the final v0.3.0 release, and additional changes are still planned.

Lumen Streets now opens into a navigable city nightscape, with global map coverage, architectural lighting and 51 modeled landmark assemblies across eight curated starting views.

- The showcase pairs Shanghai/Guangzhou, Taipei/Kaohsiung, Sapporo/Yokohama and Seattle/Lower Manhattan, with an urban waterfront in every pair. See the [inventory and capacity evaluation](../SHOWCASE.md).
- Settings replaces Light & motion and adds live landmark names. View links and scene files retain this switch independently of export labels.
- Buildings use varied window layouts, facade colours, roof lighting and red obstruction lights. Grouped map footprints are handled individually, and redundant building outlines are suppressed.
- PNG, GIF and video share a framing preview with common desktop and phone ratios, custom ratios, soft edge shading and optional place and landmark names.
- Videos run from 30 seconds to five minutes. MP4 is used when supported, with WebM as a fallback. GIF remains a six-second preview.
- Scene files preserve the view, composition settings and traffic state. Embedded views can include captions and edge shading.
- Landmark contributors can download a ZIP containing the GLB, placement, creator, license and preview image for GitHub review.

Map coverage and height detail vary by location. Lighting and traffic are artistic simulations. Imported models remain local until their creator submits a contribution.

## Changes from v0.2.0

The 3D editor replaces the 2D editor entry point. Preset views now require online vector tiles. New scene files use a separate format; earlier 2D files and links remain readable in the legacy player, without automatic 3D conversion. Amber/Blue hour palettes and the old study export are not included in the new editor. Existing gallery and social artwork still depict v0.2.0 and will be reviewed separately before release.
