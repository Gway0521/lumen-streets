# Lumen Streets v0.1.0 — First public release

Turn real streets into animated nightscapes and export a wallpaper of a place you love.

[Try it online](https://lumenstreets.feifeihome.com/) · [Source](https://github.com/Gway0521/lumen-streets) · [繁體中文](https://github.com/Gway0521/lumen-streets/blob/main/README.zh-TW.md)

![Sapporo after dark](https://raw.githubusercontent.com/Gway0521/lumen-streets/v0.1.0/docs/images/social-cover.gif)

Map data © [OpenStreetMap contributors](https://www.openstreetmap.org/copyright), ODbL. Animation from an actual application export; traffic and lighting are artistic simulations.

## Make a nightscape

- Explore eight bundled places without an account or API key, or search for a neighbourhood through the included map server.
- Shape the light with three palettes, moving cars and trains, landmark names and framing controls.
- Export PNG wallpapers, GIF previews and MP4/WebM videos where supported by the browser. Add optional place titles or leave room for desktop icons.
- Save complete scene files, share bundled-place player links or embed a scene.
- Use the editor in English or Traditional Chinese, online or on your own server.

This release also includes a fix for a reproduced Android/Adreno startup rendering failure, direct GitHub links in the editor and export results, and social preview metadata for the editor and player.

## Get started

Use the online demo, or install Node.js 24 and run `npm ci` followed by `npm run dev` from the source checkout.

For self-hosting, download `lumen-streets-v0.1.0-site.tar.gz` and its checksum. Extract it and follow the included `HOSTING.md`; the prebuilt server requires Node.js 24 but no runtime npm install. Source is also available in `lumen-streets-v0.1.0-source.tar.gz` and through the site's source page.

## Known limits

- Videos restart with a cut; they are not seamless loops. Native wallpaper installation and iPhone Live Photo conversion are not included.
- Video encoding depends on the browser and device. Physical iPhone/Safari coverage remains unverified; long high-resolution exports need substantial temporary storage.
- Dense maps can take time to prepare. Search and imports depend on map-provider availability and configured request budgets; bundled maps remain available without those services.
- Direct player links use bundled maps. Imported places can be shared as complete scene files or hosted beside the player.

Version 0.1.0 is an early release: interfaces may evolve. Code is AGPL-3.0-only; OpenStreetMap data remains under ODbL. See [compatibility](https://github.com/Gway0521/lumen-streets/blob/v0.1.0/docs/COMPATIBILITY.md) and [attribution](https://github.com/Gway0521/lumen-streets/blob/v0.1.0/ATTRIBUTION.md).

Bug reports, translations and examples of difficult street layouts are welcome. Please include your browser, device and steps to reproduce.
