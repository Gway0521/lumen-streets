# 放入一座城市地標

[English](3D-LANDMARKS.md) · [3D 概覽](3D-ARCHITECTURE.zh-TW.md)

預覽版接受本機 GLB 和定位資料，不會上傳、發布模型、修改社群模型目錄，也不會自動移除下方 OSM 建築。匯入模型是用來視覺檢查的覆蓋物；六個內建地標則沿用原版有來源身份的替換規則。

## 製作模型

優先製作從空中容易辨識的原創低面數輪廓，把幾何用在屋頂、退縮、開口及特殊結構；省略微小室內細節。使用少量材質、節制的暖色點綴，讓街道仍是最明顯的連續亮部。

輸出 **glTF 2.0 二進位 (`.glb`)**，Y 軸向上、單一場景，套用物件變換。匯入器會水平置中、把最低點放在地面，再縮放到指定高度。旋轉控制沿垂直軸轉動，請在地圖上確認朝北方向。

| 限制 | 目前數值 |
| --- | --- |
| 檔案大小 | 8 MiB |
| 場景實例合計三角形 | 20,000 |
| 場景實例合計頂點 | 60,000 |
| 節點 | 256 |
| 網格／材質 | 128／64 |
| 緩衝 | 一份內嵌二進位 buffer |
| 幾何 | 靜態三角形 |
| 貼圖、動畫、骨架、壓縮及擴充 | 預覽版不接受 |

請使用材質基本色，目前以不受光源影響的材質呈現，讓夜色較可預期。貼圖與自發光通道需要之後的材質管線。匯入器不載入任何外部資源，並在渲染前檢查區塊、accessor 範圍、循環階層及重複實例造成的幾何膨脹。

## 預覽與儲存

1. 開啟「地標模型」，選擇 GLB。
2. 填寫創作者、授權、公尺高度與旋轉角度。
3. 把鏡頭中心移到建築位置，選擇「放置於地圖中心」。
4. 旋轉和縮放檢查輪廓；「移除模型」會釋放其資源。
5. 選擇「儲存定位資料」，把下載的 `landmark.json` 和原始 GLB 放在一起。

定位資料包含版本、檔名、SHA-256、經緯度、高度、旋轉、創作者、授權及三角形數。檔名與作者文字只是資料，不會當作程式執行。未來公開目錄仍需獨立驗證內容雜湊與授權，填寫授權欄位不代表已取得權利。

分享與嵌入連結不包含模型，模型只存在本次頁面工作階段。PNG／GIF／影片會包含已放置的模型；公開散布作品時，仍須保留適用的創作者及授權資訊。

## 後續投稿流程

規劃中的可重用單位是有版本的模型套件：模型、地理定位、來源授權與預覽圖。公開服務需要上傳儲存、獨立檔案驗證、人工審核、依內容雜湊保存的永久網址、授權清單、空間索引、明確 OSM 替換規則與多層細節。這些託管功能尚未由本機匯入按鈕實作。

投稿應附高度來源及清楚的模型授權；不要使用未授權的商業地圖網格或模型。更新應保留舊內容雜湊，讓已存場景可選擇先前版本。
