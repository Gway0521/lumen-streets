# 投稿城市地標

[English](3D-LANDMARKS.md) · [架構](3D-ARCHITECTURE.zh-TW.md)

把你所在城市的建築帶進 Lumen Streets。放置本機 GLB、確認外觀，再下載投稿包交由 GitHub 審核。

## 準備模型

製作原創低面數模型，把細節放在俯視時可辨認的屋頂、退縮、開口及特色結構。使用基本材質色，保留少量暖色亮部。

匯出 **glTF 2.0 binary（`.glb`）**，Y 軸向上、單一場景，並套用物件變換。匯入器會水平置中、讓最低點落在地面，再縮放至指定高度；旋轉控制沿垂直軸轉動。

| 限制 | 數值 |
| --- | --- |
| 檔案大小 | 8 MiB |
| 含實例的三角形 | 20,000 |
| 含實例的頂點 | 60,000 |
| 節點 | 256 |
| 網格／材質 | 128／64 |
| 二進位緩衝 | 一個內嵌緩衝 |
| 幾何 | 靜態三角形 |

使用未壓縮幾何和基本材質色。匯入器不接受貼圖、動畫、骨架、擴充及外部資源。材質以無光照方式顯示，不保留自發光通道；載入前會檢查檔案區塊、存取範圍、節點階層及幾何預算。

## 放置與投稿

1. 開啟「地標模型」，選擇 GLB。
2. 填寫建築名稱、創作者、授權、高度（公尺）及旋轉角度。
3. 將地圖中心移到建築位置，選擇「放置於地圖中心」。
4. 旋轉和縮放，檢查輪廓及與鄰近建築的關係。
5. 選擇「下載投稿包」，再前往 GitHub 投稿並附上 ZIP。

投稿包包含 `model.glb`、`landmark.json`、`preview.png` 和 `README.txt`。定位檔記錄名稱、SHA-256、經緯度、高度、旋轉、創作者、授權及三角形數量；GLB 保留原始內容。

投稿時請描述建築，附上高度與輪廓的參考來源。使用第三方幾何時，列出來源及授權；也請指出應被取代的底圖建築與需要保留的附屬建物。模型發布前會審查幾何、定位、外觀、署名及替換規則。

本機放置會保留底圖建築，方便檢視位置。視角連結和場景檔不包含 GLB。圖片和影片會包含已放置的模型；公開分享時請保留創作者與授權署名。
