# 投稿城市地標

[English](3D-LANDMARKS.md) · [架構](ARCHITECTURE.zh-TW.md)

把你所在城市的建築帶進 Lumen Streets。放置本機 GLB、確認外觀，再下載投稿包交由 GitHub 審核。

內建展示已有 51 組原創參數模型，可從[精選城市與地標](SHOWCASE.zh-TW.md)瀏覽。下列 GLB 投稿限制與內建參數模型不同。

## 準備模型

製作原創低面數模型，把細節放在俯視時可辨認的屋頂、退縮、開口及特色結構。使用基本材質色，保留少量暖色亮部。

匯出 **glTF 2.0 binary（`.glb`）**，Y 軸向上、單一場景，並套用物件變換。匯入器會水平置中、讓最低點落在地面，再縮放至指定高度；旋轉控制沿垂直軸轉動。

| 限制 | 數值 |
| --- | --- |
| 檔案大小 | 8 MiB |
| 含實例的三角形 | 20,000 |
| 含實例的頂點 | 60,000 |
| 節點 | 256 |
| 網格／材質 | 128／64 |
| 二進位緩衝 | 一個內嵌緩衝 |
| 幾何 | 靜態三角形 |

使用未壓縮幾何和基本材質色。匯入器不接受貼圖、動畫、骨架、擴充及外部資源。材質以無光照方式顯示，不保留自發光通道；載入前會檢查檔案區塊、存取範圍、節點階層及幾何預算。

## 放置與投稿

1. 開啟「地標模型」，選擇 GLB。
2. 填寫建築名稱、創作者、授權、高度（公尺）及旋轉角度。
3. 將地圖中心移到建築位置，選擇「放置於地圖中心」。
4. 旋轉和縮放，檢查輪廓及與鄰近建築的關係。
5. 選擇「下載投稿包」，再前往 GitHub 投稿並附上 ZIP。

投稿包包含 `model.glb`、`landmark.json`、`preview.png` 和 `README.txt`。定位檔記錄名稱、SHA-256、經緯度、高度、旋轉、創作者、授權及三角形數量；GLB 保留原始內容。

投稿時請描述建築，附上高度與輪廓的參考來源。使用第三方幾何時，列出來源及授權；也請指出應被取代的底圖建築與需要保留的附屬建物。模型發布前會審查幾何、定位、外觀、署名及替換規則。

本機放置會保留底圖建築，方便檢視位置。視角連結和場景檔不包含 GLB。圖片和影片會包含已放置的模型；公開分享時請保留創作者與授權署名。

## 精度與建模難度

模型是原創低面數的鳥瞰輪廓，著重退縮、屋頂、球體、開口及支架。高度來源分成原有已核對來源、OSM 高度標籤與明列的展示近似值；外框與建築部件的高度分開判讀。例如 85 大樓的外框標籤為 50 公尺，而模型採含塔尖的約 378 公尺；紐約部分外框只表示較低主體。完整結構、細部尺寸、曲面、立面和照明均非測繪重建。

| 類型 | 目前例子 | 主要難點 | 後續精修成本 |
| --- | --- | --- | --- |
| 方形塔樓、逐層退縮 | 世貿四號、30 Park Place、南山廣場 | 基座與高樓部分的比例、朝向、原地圖重疊 | 低至中 |
| 特殊屋頂、歷史建築 | 國父紀念館、時計台、和平飯店 | 屋簷、鐘塔、屋頂和塔身辨識度 | 中 |
| 自由曲面、扭曲立面 | 歌劇院、MoPOP、港旅運中心、8 Spruce | 低面數下保留曲面輪廓；細節簡化最多 | 高 |
| 鏤空結構與大跨距 | 廣州塔、摩天輪、三座橋 | 支架、纜索、開口、橋面位置及幾何用量 | 高 |

廣州塔的開放網格、摩天輪輻條與橋纜是真正幾何；橋面依來源輪廓三角化。橋塔與纜索仍是示意比例。皇后廣場及紅磚倉庫保留各棟來源位置。主要參考包括 [廣州歌劇院建築資料](https://www.zaha-hadid.com/wp-content/uploads/2019/12/guangzhouoperahouse.pdf)、[Oculus 建築設計](https://prod.calatrava.com/projects/world-trade-center-transportation-hub-new-york.html)、[札幌時計台](https://sapporoshi-tokeidai.jp/english/)、[橫濱地標塔](https://yokohama-landmark.jp/about/)、[85 大樓高度資料](https://www.skyscrapercenter.com/building/t-c-tower/338)。

| **合計** | **51** | **50,355** | **9.221** |

地標資料、模型生成程式與載入規則合計約 **179 KiB 原始文字、24 KiB gzip**。測量範圍為這三份來源，不含共用模型庫中的六座模型定義；整站傳輸量另計。內建模型由程式產生，不需各自下載 GLB 或貼圖。

每個視野最多保留 **90,000 個地標頂點，約 30,000 個三角形／5.5 MiB 頂點屬性**，並計入原本桌面 700,000／手機 280,000 的總立面頂點預算；超額模型整組略過，保留普通地圖建築，不畫半座模型。附近地標先保留幾何，再把餘額交給普通建築。模型合併進共用立面網格，不為每座新增一次繪製呼叫。

依目前平均複雜度，同一視野約可容納 **30 組**；如果都是廣州塔等鏤空複雜結構，約 **2–5 組**就可能接近預算。這是幾何預算估計，不是手機幀率保證。

模型只在附近生成。擴大目錄前應加入地區拆包與空間索引，並測量下載、解碼、切換和實機記憶體。目前驗證範圍為這 51 組。

內建模型涵蓋精選視角及周邊約 2–3 公里的主要建築。定位、來源高度及替換輪廓見[模型目錄](../src/three/showcase-landmarks.json)。原始圖資 © [OpenStreetMap contributors · ODbL](https://www.openstreetmap.org/copyright)。
