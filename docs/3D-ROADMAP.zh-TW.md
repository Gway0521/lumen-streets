# 3D 開發路線

[English](3D-ROADMAP.md)

目前預覽已建立全球移動、WebGL 2 深度渲染、有預算的背景建模、六個原版地標、車流、短匯出與本機 GLB 定位。後續依可觀察的驗收條件逐步推進。

遠景修訂已加入方向一致的旋轉、較寬的觀賞範圍、獨立建築圖磚、超出細節預算時保留的實例量體，以及原版預設地景繪製。目前仍是美術開發預覽；涵蓋更多建築不等於已通過美術或手機實機驗收。

## 1. 美術與實機基準

以橫式、直式檢查上海、札幌、東京及台北，對照原版實際匯出，調整連續路光、屋頂層次、街區明暗及地標輪廓。將預設街區的植被與岸邊反射擴充至全球地景。測試 Android／iPhone 實機、長時間移動、發熱、context 遺失及影片編碼；每筆測量註明裝置、瀏覽器、鏡頭、暖機、幀距與記憶體範圍。

## 2. 串流幾何品質

從有預算的整個視野重建，進一步改為空間區塊重用，優先載入近景和可見地標，每幀限制 GPU 上傳量，加入 LOD 切換緩衝。新區塊就緒前保留遠景輪廓。擴充雙坡、四坡、金字塔與曲面屋頂，保留孔洞，避免整棟與部件重疊。

需要時採更完整的圖磚規格，加入 OSM 身份、部件、屋頂、交通層級、單行道及來源版本。讓車流跨越區塊並加入全球列車。正式營運前建立可行的自架資料管線；補上八個快照的離線底圖。

## 3. 桌布與場景保存

在目前固定幀率影片的基礎上，提供與視窗形狀無關的構圖、長時間匯出、播放清單與可選的無縫鏡頭循環。新的 3D 場景格式需保存來源版本、模型雜湊、渲染語意與車流狀態；2D 場景沿用原讀取器，遷移須明確處理。

## 4. 社群地標

把本機 GLB＋定位檔擴充為可審核投稿，加入身份驗證、上傳儲存、驗證工作、人工審核、授權、地理索引、歷史版本及明確替換規則。依投影大小載入簡化或細緻模型，儲存層可替換，避免渲染器綁定單一服務。

## 發布條件

公開 3D 版本需要通過美術比較、實機測量、長時間移動的記憶體穩定性、正確匯出說明、可恢复的資料服務故障，以及軟體／地圖／模型來源審核。在條件完成前保留原版 2D。WebGPU 應獨立實測評估，不是第一個可用 3D 發行版的必要前提。
