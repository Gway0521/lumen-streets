# 架構

[English](ARCHITECTURE.md)

MapLibre 與 Three.js 共用 WebGL2 畫面及深度緩衝。MapLibre 負責底圖、鏡頭及圖磚，Three.js 負責建築、地標、植栽和移動燈光。編輯器、匯出與嵌入共用渲染流程。

## 資料流程

1. 依視角選取周圍 zoom-14 圖磚。
2. Node 建築服務透過 HTTP Range 讀取 Overture PMTiles；Python 在背景補充有地理覆蓋的高度資料。
3. 瀏覽器 worker 建立立面、地標、地景遮罩及車流路網。
4. 渲染器替換場景並釋放舊 GPU 資源。匯出期間固定建築版本及車流狀態，結束後恢復。

OpenFreeMap 提供道路、水面、土地覆蓋與平面底圖。內附快照補充覆蓋區的道路和鐵道拓樸。建築高度與來源標示由[高度服務](BUILDING-HEIGHTS.zh-TW.md)供應。

## 畫面與資源

一般建築使用批次立面幾何，依固定種子分配九種建築風格、材質和窗光。遠處改用簡化實例；51 組[地標](SHOWCASE.zh-TW.md)替換對應輪廓並併入立面幾何。樹木採實例繪製，水面以附近道路及推估岸邊燈光產生風格化倒影。

桌面／手機分別限制 700,000／280,000 個詳細立面頂點，其中最多保留 90,000 個頂點給地標。每個視角最多選取 180／96 個建築圖磚，編碼快取為 24／8 MiB，同時下載 4／2 個。這些預算不包含瀏覽器、底圖與驅動程式開銷；完整表格見[英文架構文件](ARCHITECTURE.md)。

CityStream 同時只處理一項幾何工作，合併後續更新並拒絕過期結果。替換場景時釋放舊幾何、材質附屬資源及位圖；進入遠景後釋放詳細城市資源。背景分頁停止車流繪製，暫停時只因互動重繪。

建築與快照請求設有 15 秒期限，包含回應內容下載。暫時性網路或 HTTP 錯誤最多再試兩次，取消會中止請求及重試等待。超過上限後，使用者可直接重試目前視角；資料格式錯誤及永久性 HTTP 錯誤不會自動重試。

共用幾何、固定種子亂數、道路參數、地區與快照解析集中於 src/shared/，依賴檢查會阻止循環匯入。worker 訊息、高度圖磚、3D 場景與匯出檢查點納入型別檢查，外部資料另有執行時驗證。瀏覽器測試與效能量測方式見[測試文件](TESTING.md)。

## 功能邊界

預設地區也需要線上圖磚。各地輪廓及實測高度完整度不同。車流尚未跨所有圖磚與快照邊界持續銜接，全球鐵路及完全離線場景仍列於[路線圖](ROADMAP.md)。

舊 Canvas 播放器保留既有場景格式及幾何版本，供唯讀播放使用。另見[場景](SCENES.md)、[測試](TESTING.md)、[部署](HOSTING.zh-TW.md)及[立面照明](3D-FACADES.zh-TW.md)。
